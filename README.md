# NEON FUTO STUDIO 🎨⌨️

تطبيق أندرويد لإنشاء وتخصيص ثيمات لوحة المفاتيح FUTO Keyboard.

## ✨ المميزات
- 🎨 6000 لون مع معاينة حية
- 🔷 500 شكل زر (قلوب، نجوم، سداسي، إلخ)
- 🖼️ 12 خلفية جاهزة (طبيعية، فضاء، مدن)
- ✍️ رفع خطوط مخصصة (TTF/OTF)
- 📐 9-slicing للحدود
- 🔗 Matchrules لربط الصور بالأزرار
- 📦 تصدير ZIP متوافق مع FUTO Keyboard

## 🚀 البناء
- APK يُبنى تلقائياً عبر GitHub Actions.
- اذهب إلى تبويب Actions وحمّل الـ APK من Artifacts.
